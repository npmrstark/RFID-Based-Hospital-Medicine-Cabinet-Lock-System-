EM-18 RFID Reader

16x2 LCD

Component Pin	LPC2129 Pin
D0 - D7	P0.8 - P0.15
RS	P0.16
E	P0.17
RW	GND
VSS, K	GND
VDD, A	5V
VEE	10k pot middle pin

L293D Motor Driver

Component Pin	LPC2129 Pin
IN1	P0.18
IN2	P0.19
EN1	5V
VCC1	5V
VCC2	Motor supply
GND	GND
OUT1, OUT2	DC motor terminals

LED, Buzzer, Switch

Buzzer	Negative	P0.21
Push Switch	One side	P0.22
